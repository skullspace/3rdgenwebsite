# Skullspace 3rd Generation Website

Our 3rd generation, static website, including a special
http://lofi.skullspace.ca version (to have its own branch perhaps someday)

The `index.html` file is the lo-fi version of the website and, as of Nov 1 2026,
it is the main website as well. Currently there is a cronjob that runs every 10
minutes that syncs this file to skullspace.ca homepage and website.

The rest of this repo is the next generation and will be used on Skullspace.ca
once it is ready. It is built with [Astro.build](https://astro.build).
