# Skullspace 3rd Generation Website

This is our 3rd generation, static website. Deployed with the main site is a special http://lofi.skullspace.ca version
(to have its own branch perhaps someday)

Our first generation website was also static. The 2nd was WordPress. Returning to static is a return to form for us.

In our mainline branch we're looking for minor, incremental changes. Our number 1 ask is a stylesheet. Also welcome are html additions to the front page and additional pages with more information from our prior website. If and when javascript is introduced the preference is to have good fallbacks without it.

Significant re-works of the site and architecture should go into branches for discussion. 

The architecture here is clean, human readable, directly hand edited html. At some point it may make sense for us to use some kind of site building framework, but it makes sense to get alignment with other Skullspace folks first. The astro branch shows a good example of what re-imagining the Skullspace site could look like built with the framework astro. Opinions on Astro and alternatives are welcome. Also welcome is the pushing of further illustrative branches showing our options for future architectures.

Documented machine generated assistance ("ai" etc) is okay, but strong human agency and oversight is essential. The site code should be understandable and editable by humans and the final commits human authored. More on our views in AGENTS.md.
